# 获取 src 目录结构

当需要了解 **src 目录与模块结构**（替代原 architecture.text）时：

1. **进入项目根目录**下的 `src`，执行 `tree` 获取目录树。
2. 在终端执行（从 frontend 仓库根目录）：
   ```bash
   cd src && tree
   ```
   若希望只显示目录或限制层级，可使用：`tree -d`（仅目录）或 `tree -L 2`（最多 2 层）等。
3. 根据输出的目录树理解模块划分、features 与公共组件等，再动手改代码。
